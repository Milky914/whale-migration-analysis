# Whale Migration Analysis
Exploratory data analysis of blue whale tracking data from Movebank.

## Goal:
Find which regions in the Southern Ocean have the most whale observations.

## Data
 - Source: Movebank (open database)
 - File: Antarctic blue whales, east Antarctic sector of the Southern Ocean
 - 835 rows, 16 columns

## Tools
  - Python
  - pandas
  - matplotlib

## Key findings
1) Most observations are concentrated near the coast of Antarctica
2) Top region: 88/-62 (57 observations) — south of Australia
3) Second: 179/-68 (43 observations) — near the 180° meridian
